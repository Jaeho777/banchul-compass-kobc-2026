반출나침반 시연 실행 안내

1. 반출나침반_시연.html을 Chrome 등 브라우저에서 열고 합성 초기화를 누릅니다.
2. 기본 상태: 8건, 위험2건, 확인필요3건, 산정 가능한 미반출4건의 모의 부분합580,000원.
3. CNT-104: 트럭 예약일 2026-10-31, 사유 입력 후 입력 저장 → 사유 입력 후 승인 → 사유 입력 후 조치완료.
4. CNT-505: D-3 알림은 없지만 2일 초과·400,000원 모의 노출을 확인합니다.
5. CNT-808: 실제 반출일2026-10-30, 모의 정산액12000, 사유 입력 후 반출 확인 → 사후관리 차이 확인.
6. 지연 슬라이더, 달력일/영업일/구간요율, CSV 내보내기·입력, JSON 백업·복원과 브라우저 저장을 확인합니다.

모든 데이터는 합성입니다. 실제 계약·개인정보를 입력하지 마십시오. 학습된 AI·실시간 연동·실제 비용 절감은 없습니다. 브라우저 저장은 인증된 감사로그가 아닙니다. CSV는 합성8건 전체만 받으며 반출·정산·승인 상태는 수입하지 않습니다. 시연 실행에는 설치가 필요하지 않습니다.
