## 사용 방법
1. 이 ZIP 압축을 해제한 폴더를 Codex 작업환경에 올린다.
2. `CODEX_붙여넣기_프롬프트.md`를 열어 전체를 Codex 첫 메시지로 보낸다.
3. P0에 해당하는 공식 지정 HWP 서류부터 확보한다. 이 ZIP에는 공식 HWP 원본이 들어 있지 않다.
4. Codex가 준비한 최종 업로드 파일을 공식 접수 페이지에서 **사용자가 직접** 제출한다. 접수 확인/접수번호를 보관한다.
